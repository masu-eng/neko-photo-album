# neko-photo-album

10歳ごろの三毛猫、ミミのフォトアルバムです。1枚の `index.html` で動く静的サイトで、GitHub Pages でもそのまま公開できます。

## 見る

`index.html` をブラウザで開くだけです。サーバーは不要です。

## 機能

- **場所でしぼりこむ**：座布団の上 / オーディオの上 / 椅子の上 / キャットタワーの上 / 近くで見ると / ほかの場所
- **さがす**：キャプションや場所の名前で検索できます（例：お昼寝）
- **お気に入り**：写真右上の ♡ を押すと保存され、「♡ お気に入りだけ」でしぼりこめます。ブラウザに保存されるので、次に開いたときも残ります
- **今日のミミ**：日替わりで1枚をピックアップして、ページ上部に表示します
- **ランダム**：🎲 ランダムで、しぼりこみ中の写真から1枚を大きく表示します
- **ライトボックス**：写真をタップすると大きく表示します。枚数カウンター（例：6 / 20枚）と場所、保存ボタン、スライドショー（3秒ごと）、スワイプ、キーボード操作（← → で移動、F でお気に入り、Esc で閉じる）に対応しています
- **明るさの切り替え**：🌙 ダーク / ☀️ ライトを手動で切り替えられます。選んだ設定はブラウザに保存されます
- **キャプション表示**：写真の下にキャプションがそのまま表示されます。セクションごとの枚数と全体の枚数は自動で数えています

## 写真を追加する

写真は `index.html` の中に埋め込まれています。`neko/` に JPG を置くだけでは表示されないので、次の手順が必要です。

1. 写真を幅 800px 程度にリサイズして、JPEG として base64 に変換する
2. 入れたいセクションの `<div class="g">` の中に、ほかの写真と同じ形の `<figure class="ph">…</figure>` を追加する（`data-i` は 0 から通し番号で、ほかの写真と重ならないようにする）
3. フッターの枚数は自動で更新されるので、書き換えは不要です

`neko/` フォルダには元の高画質 JPG を保管しています。
